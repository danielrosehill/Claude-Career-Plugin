## White-hat rule

All research in this workspace is white-hat. Use only publicly available sources:

- Public job postings (employer sites, LinkedIn, Indeed, etc.)
- Salary platforms (Levels.fyi, Glassdoor, Payscale, Salary.com, LinkedIn Salary Insights)
- Government wage data (BLS, Eurostat, national stats offices)
- Regulatory filings (SEC for exec comp)
- Anonymous community sources (Blind, Fishbowl) — treat as signal, not fact
- Published compensation surveys

**Never** impersonate recruiters, submit fake applications, scrape behind auth, or social-engineer contacts.

## Conventions

- **Confidence labels on every data point:** `Confirmed` (employer/regulator published), `Reported` (salary platform aggregate), `Inferred` (triangulated).
- **Separate base / bonus / equity** wherever the source allows it. Don't collapse to a single number unless the source did.
- **Cite everything.** Every table row or figure needs a source link.
- **Refresh dates.** Comp data goes stale fast. Every analysis file carries `Last updated: YYYY-MM-DD`.
