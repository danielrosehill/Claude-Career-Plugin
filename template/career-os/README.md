# Career-OS workspace

A unified workspace for employment + freelance/consulting discovery, research, and outreach. Consumed by the [`career` Claude Code plugin](https://github.com/danielrosehill/Claude-Career-Plugin).

See `CLAUDE.md` for full directory map and command list.

## Quick start

```
/career:onboard         # populate ground-truth.md, write config, install companions
/career:research-company <name>   # six-brief deep-dive on a target
/career:suggest companies --domain=<your-niche>
```

## Privacy

Personal. If you push to GitHub, push **private**. The plugin's `new-workspace` skill warns about this on creation.
