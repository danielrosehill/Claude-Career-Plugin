# Warm Follow-up — example

Use after a prior conversation, intro, or meeting. Reference the actual thing you discussed — never generic.

## Variables

- `{{contact_first_name}}`
- `{{prior_context}}` — what you discussed last time, in one phrase.
- `{{the_thing_you_promised}}` — link / doc / intro you said you'd send.
- `{{forward_motion_ask}}` — concrete next step.
- `{{your_signature}}`

## Body

Subject: Re: {{prior_thread_subject}}

Hi {{contact_first_name}},

Thanks again for {{prior_context}}. I said I'd follow up with {{the_thing_you_promised}} — here it is: {{link_or_attachment}}.

{{forward_motion_ask}}

{{your_signature}}

## Notes for the agent

- Always reply in the prior thread if one exists; new subject only if cross-channel.
- Deliver what you promised before asking for the next thing.
- One ask, max.
