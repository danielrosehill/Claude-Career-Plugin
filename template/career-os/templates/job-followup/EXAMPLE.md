# Job Follow-up — example

Use after submitting an application, after an interview, or to nudge a stalled process.

## Variables

- `{{contact_first_name}}`
- `{{role_title}}`
- `{{date_of_prior_step}}` — application date / interview date.
- `{{value_add_signal}}` — one concrete thing reinforcing fit (a project shipped, a new cert, a relevant talk).
- `{{your_signature}}`

## Body

Subject: Following up — {{role_title}}

Hi {{contact_first_name}},

Following up on the {{role_title}} application from {{date_of_prior_step}} — I wanted to share {{value_add_signal}}, which feels relevant to what we discussed about {{thing_from_jd_or_interview}}.

Happy to provide anything else that would help — and equally happy to hear if the role's moved in a different direction.

{{your_signature}}

## Notes for the agent

- Never sound impatient. Never imply they're slow.
- Add one new piece of value — never just "checking in."
- Use after 7 days post-application, 5 days post-interview. Sooner is pushy.
